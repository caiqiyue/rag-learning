## 一、RAG核心概念

### 1.1 什么是RAG？

**RAG** = **R**etrieval（检索） + **A**ugmented（增强） + **G**eneration（生成）

RAG即检索增强生成，通过检索外部知识库为LLM提供上下文信息来增强答案生成。RAG本质是让大模型学会"查资料"后再回答问题，类似于开卷考试而非闭卷考试。

### 1.2 RAG的类比理解

| 对比项 | 传统AI模型（闭卷考试） | RAG系统（开卷考试） |
|--------|------------------------|---------------------|
| 回答方式 | 仅依靠模型记忆中的知识 | 先查阅资料，再归纳整理 |
| 知识来源 | 训练数据（有时效性） | 实时检索的最新资料 |
| 答案准确性 | 可能有幻觉 | 有据可查 |
| 信息来源 | 无法追溯 | 可追溯验证 |

### 1.3 传统大模型的局限性

1. **知识可能过时** - 训练数据存在时效性，无法回答发布后发生的事件
2. **会产生幻觉** - 一本正经地胡说八道，生成看似合理但违背事实的内容
3. **无法访问私有知识** - 学习不到企业内部或个人私有知识库
4. **回答缺乏出处** - 无法给出具体的引用来源供验证
5. **上下文限制** - 大部分模型限制在128K左右

### 1.4 RAG的核心本质

**让大模型学会"查资料"后再回答问题**

- 网络搜索资料
- 知识库存储资料

既保证了答案的准确性、时效性，又提供了可追溯的信息来源。

## 二、RAG的优势

1. **灵活性、适应性强** - 可接入最新、私有、不断更新的数据
2. **提高准确性** - 回答有据可查，减少幻觉
3. **成本相对低** - 无需重新训练或微调模型，只需维护知识库
4. **个性化程度高** - 特别适合专业领域知识问答

## 四、RAG工作原理

### 4.1 两阶段工作流程

RAG系统分为两个阶段：

#### 阶段一：准备阶段（离线知识库构建）

```
数据源接入 → 文档解析 → 文档分割 → 向量化 → 向量存储
```

| 步骤 | 说明 |
|------|------|
| 1. 数据源接入 | 收集PDF、Word、网页等各类文档 |
| 2. 文档解析 | 提取纯文本内容 |
| 3. 文档分割 | 将长文档切分成小片段（chunks） |
| 4. 向量化 | 将文本转换为数学向量（Embeddings） |
| 5. 存储 | 将向量存入向量数据库 |

#### 阶段二：问答阶段（在线推理）

```
用户提问 → 问题向量化 → 相似度检索 → 提示增强 → 答案生成
```

| 步骤 | 说明 |
|------|------|
| 1. 用户提问 | 输入自然语言问题 |
| 2. 问题向量化 | 将问题转换为向量 |
| 3. 相似度检索 | 在向量数据库中查找最相关的文档 |
| 4. 提示增强 | 将检索到的文档+问题组合成新提示 |
| 5. 答案生成 | LLM基于增强提示生成最终答案 |

### 4.2 核心组件作用

| 组件 | 作用 |
|------|------|
| **Embedding模型** | 将文本转换为向量表示 |
| **向量数据库** | 存储和检索向量（FAISS、ChromaDB、Milvus等） |
| **LLM大模型** | 基于增强提示生成最终答案 |
| **提示模板** | 组合检索结果与用户问题 |

### 4.3 向量化与相似度计算

向量化原理：
- 将文本转为向量（一组数字）
- 向量间可计算距离，距离远近 = 语义相似度

常用相似度计算方法：
- **余弦相似度** - 夹角越小越相似（值越大越相似）
- **欧氏距离** - 点间距离越小越相似
