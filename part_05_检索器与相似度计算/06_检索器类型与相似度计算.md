## 知识点讲解

### 1. 相似度度量基础

在RAG系统中，相似度度量是判断查询与文档相关性的核心机制。主要有三种相似度计算方式：

#### 余弦相似度（Cosine Similarity）

余弦相似度衡量两个向量方向的相似程度，取值范围为[-1, 1]。

**计算公式**：
```
cosine_similarity = (A · B) / (||A|| × ||B||)
```

**特点**：
- 只考虑向量方向，不考虑向量大小
- 值越接近1表示两个向量越相似
- 值越接近-1表示两个向量越相反
- 值接近0表示两个向量正交（无相关性）

**适用场景**：文本嵌入向量的相似度计算、语义匹配

#### 点积（Dot Product）

点积是向量对应元素相乘后的累加和，取值范围无限制。

**计算公式**：
```
dot_product = Σ(Ai × Bi)
```

**特点**：
- 对于归一化向量，点积等价于余弦相似度
- 值越大表示两个向量越相似
- 计算效率高，广泛用于ANN（近似最近邻）检索

**适用场景**：大规模向量检索、需要考虑向量magnitude的场景

#### 欧氏距离（Euclidean Distance）

欧氏距离是向量空间中两点之间的直线距离，取值范围为[0, +∞)。

**计算公式**：
```
distance = √(Σ(Ai - Bi)²)
```

**特点**：
- 值越小表示两个向量越相似
- 通常通过公式转换为相似度：similarity = 1 / (1 + distance)

**适用场景**：聚类分析、推荐系统

### 2. Top-K检索与阈值检索

#### Top-K检索

Top-K检索返回最相似的前K个文档，是RAG系统中最常用的检索方式。

**工作流程**：
1. 计算查询向量与所有文档向量的相似度
2. 按相似度降序排列
3. 返回前K个文档

#### 相似度阈值检索

阈值检索返回所有超过相似度阈值的文档，结果数量不固定。

**工作流程**：
1. 计算查询向量与所有文档向量的相似度
2. 过滤掉相似度低于阈值的文档
3. 返回满足条件的文档

### 3. LlamaIndex检索器类型

#### VectorIndexRetriever（向量检索器）

**原理**：基于密集向量检索（Dense Retrieval），通过Embedding模型将文本转换为向量，计算余弦相似度进行排序。

**特点**：
- 能理解语义和概念，泛化能力强
- 对关键词不敏感
- 向量构建成本较高

**适用场景**：语义相似度匹配、自然语言查询

#### BM25Retriever（关键词检索器）

**原理**：基于传统搜索引擎技术（BM25算法），依赖倒排索引，精确匹配关键词。

**特点**：
- 速度快，精确匹配效果好
- 无法理解语义
- 同义词、近义词问题难处理

**适用场景**：专业术语匹配、代码搜索、精确匹配需求高的场景

#### QueryFusionRetriever（融合检索器）

**原理**：结合多种检索策略（如向量检索+BM25），通过RRF（Reciprocal Rank Fusion）算法融合结果。

**特点**：
- 兼顾语义召回和关键词精确匹配
- 召回率和精度更高
- 配置相对复杂

**适用场景**：生产环境首选，兼顾语义和关键词的场景

### 4. 检索器选择建议

| 场景 | 推荐检索器 | 说明 |
|------|-----------|------|
| 初步探索 | VectorIndexRetriever | 快速搭建语义检索系统 |
| 专业领域 | BM25Retriever / HybridRetriever | 需要精确匹配术语 |
| 生产环境 | QueryFusionRetriever | 最全面和最精准的召回效果 |
| 高精度需求 | HybridRetriever + Reranker | 粗召回+精排的黄金组合 |

### 5. 混合检索与重排序

**混合检索流程**（适合生产环境）：
1. **粗召回阶段**：使用HybridRetriever，Top-K设为10~20
2. **精排阶段**：使用Reranker（如BGE-Reranker）重新排序
3. **最终输出**：保留Top-N=3~5个最相关结果

这种"检索 -> 重排"的管道模式被实践证明是兼顾召回率与精度的黄金标准。
